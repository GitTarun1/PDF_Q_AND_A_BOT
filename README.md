# 📚 PDF Q&A Chatbot (Groq + HuggingFace + FAISS)

A lightweight and efficient Retrieval-Augmented Generation (RAG) web application built using **Streamlit**. This bot allows you to upload any PDF document and ask questions about its content. It retrieves context using a local vector store and answers queries using the Groq API.

## 🔍 Detailed File & Folder Explanations

### 1. `.devcontainer/`
This folder is used to configure an isolated development environment inside a Docker container.
* **`devcontainer.json`**: Tells VS Code how to build and mount the project into a Linux-based Docker container pre-installed with Python 3.11, auto-install all Python dependencies, configure VS Code extensions (Python, Pylance), and auto-start the Streamlit server on port `8501`.

### 2. `.git/` (Hidden)
* A hidden directory generated by Git that stores all project version history, branches, references, and remote repository links. Wiping and recreating this folder resets the Git commit history.

### 3. `.env` (Ignored)
* Local environment secrets file. It is used to store sensitive API keys like `GROQ_API_KEY`.
* **Important**: This file must never be committed to Git or pushed to GitHub to prevent API key exposure.

### 4. `.gitignore`
* A configuration file telling Git which files and folders to keep local (not push to GitHub).
* In this project, it ignores Python cached files (`__pycache__/`), virtual environments (`venv/`), and the private `.env` file.

### 5. `LICENSE`
* The license document for the project. It uses the permissive **MIT License** with copyright ownership assigned to the user (`GitTarun1`), protecting the author from legal liability while allowing free distribution and modification.

### 6. `app.py`
The main Python script containing the entire application logic. It is split into two major components:
* **Backend (RAG Pipeline)**:
  * **Text Extraction**: Reads the uploaded PDF file stream using `PyMuPDF` (`fitz`).
  * **Chunking**: Splits the extracted text into manageable chunks of 500 characters using LangChain's `RecursiveCharacterTextSplitter`.
  * **Vector Index**: Generates dense embeddings using Hugging Face's `all-MiniLM-L6-v2` transformer model and stores them in a local `FAISS` vector database.
  * **RAG Prompting**: Queries the vector store for similar chunks, merges them as context, and queries the **`qwen/qwen3.8-27b`** model on Groq to compile the final answer.
* **Frontend (Streamlit UI)**:
  * Implements the web interface widgets (`st.file_uploader`, `st.text_input`, status spinners) and uses `st.session_state` to cache the processed PDF.

### 7. `requirements.txt`
* Lists the Python libraries and packages required to run the application (e.g. `streamlit`, `PyMuPDF`, `langchain`, `sentence-transformers`, `faiss-cpu`, `groq`, etc.).

## 🚀 How to Run the Project Locally

### 1. Set Up Your API Key
Create a `.env` file in the root folder and add your Groq API key:
```env
GROQ_API_KEY=your_groq_api_key_here
```

### 2. Install Dependencies
Run the installation command in your terminal:
```bash
pip install -r requirements.txt
```

### 3. Launch the Application
Run the Streamlit server:
```bash
streamlit run app.py
```
Open `http://localhost:8501` in your browser.
